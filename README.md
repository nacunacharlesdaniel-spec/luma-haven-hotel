# Luma Haven Hotel
React + Vite + Supabase school demonstration hotel reservation website.

## Run
npm install
npm run dev

Copy `.env.example` to `.env` and add your Supabase URL and publishable key.
Then run `supabase/schema.sql` in Supabase SQL Editor.

Plaintext passwords are intentional for the classroom demonstration only. Do not use this authentication design in a real production system.
